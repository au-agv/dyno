# Building from source

DYNO has been built and tested on Ubuntu 22.04 using the GCC compiler version
11.4.0. While it should be possible to build DYNO and all its dependencies under
a different distribution or under Windows using the MSVC compiler, this has not
been tested and not all features may work as expected out of the box.
